Mathematical Foundations

21-Dimensional Physical Feature Extraction Specifications

Comprehensive mathematical formulations of the 12 single-receiver statistical and dynamic features alongside the 9 cross-link spatial differential metrics extracted on every 5.0-second sliding window.

Single-Receiver Features (12 Features: 6 per Receiver)
1. Mean RSSI: μ_i = (1/N) Σ RSSI_i[k]
2. Standard Deviation: σ_i = √((1/(N-1)) Σ (RSSI_i[k] - μ_i)²)
3. Fisher Skewness: γ_{1,i} = (1/N) Σ ((RSSI_i[k] - μ_i) / σ_i)³
4. OLS Trajectory Slope: β_i = Σ (t_k - t̄)(RSSI_i[k] - RSSĪ_i) / Σ (t_k - t̄)²
5. Zero-Crossing Rate: ZCR_i = (1 / 2(N-1)) Σ |sgn(x[k] - μ) - sgn(x[k-1] - μ)|
6. Baseline Shift: ΔB_i = μ_i - B_{0,i} (dB relative to calibrated baseline)
Cross-Link Differentials (9 Spatial Multi-Path Features)
13. Mean Differential: Δμ = μ_{R1} - μ_{R2}
14. Variance Ratio: VR = σ²_{R1} / (σ²_{R2} + ε)
15. Cross-Correlation: ρ_{12} = Cov(RSSI_{R1}, RSSI_{R2}) / (σ_{R1} σ_{R2})
16. Velocity Differential: Δβ = β_{R1} - β_{R2}
17-21. Dynamic Flux: ΔZCR, ΔB_{12}, max(|R1 - R2|), Combined RMS, Energy Ratio
